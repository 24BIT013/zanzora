# Zanzora Discover

A Django-powered, template-based travel website for tailor-made Tanzania and Zanzibar journeys.

## Run locally

```bash
python3 manage.py migrate
python3 manage.py runserver
```

Then visit `http://127.0.0.1:8000/`.

## Included

- Responsive editorial home page
- Journey directory with theme filtering
- Individual journey pages and sample itinerary
- Session-based journey wish list
- Database-backed trip inquiry form (available in Django admin)
- Django admin at `/admin/` after creating a superuser with `python3 manage.py createsuperuser`
